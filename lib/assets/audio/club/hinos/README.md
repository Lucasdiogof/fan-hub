# Hinos do Goiás

Coloque aqui os arquivos MP3 dos hinos, com os nomes referenciados em
`lib/features/club/data/club_songs_data.dart` (campo `audioAsset`):

- `hino_oficial.mp3`
- `hino_zeze_di_camargo.mp3`
- `hino_mr_gyn.mp3`

Depois de adicionar o arquivo, defina `audioAsset` na entrada correspondente
em `club_songs_data.dart` apontando para
`lib/assets/audio/club/hinos/<arquivo>.mp3`.
